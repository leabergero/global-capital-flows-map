OPCIÓN 1: Usar el script (RECOMENDADO)
═════════════════════════════════════════════════════════════════════

Ejecuta en tu terminal:

    bash /home/leandro/Vídeos/flujos-globales/DEPLOY_ORACLE.sh

Este script automáticamente:
  1. Conecta via SSH a Oracle
  2. Actualiza código (git pull)
  3. Instala dependencias (apscheduler)
  4. Reinicia el servicio
  5. Precalcula 6 meses de caché

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════

Si obtienes "Permission denied (publickey)":
  - Verifica que SSH keys están configuradas correctamente
  - Intenta: ssh -vvv leandro@152.70.14.73 (para debug)

Si pip install falla:
  - Asegúrate que .venv está activado
  - Prueba: source .venv/bin/activate

Si systemctl falla:
  - Asegúrate que tienes permisos sudo
  - Prueba sin sudo para verificar status
